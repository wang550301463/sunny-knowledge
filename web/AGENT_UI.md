# 问答与智能体界面

本模块使用 `agent/API.md` 的实际接口，通过已有 `ApiClient` 和 gateway 传递当前用户的 Bearer。没有前端模拟答案、默认模型或默认管理员身份。

## 页面与配置

- `/chat`：会话列表、本轮空间范围、快速问答/研发分析、提问、历史运行、取消、创建新运行重试、反馈和 Markdown 导出。
- `/chat?session=...&run=...&agent=...&configuration=...` 恢复会话、运行和固定 Agent 配置；`/runs/:runId` 可用于渠道完整结果链接，读取后补全已授权的实际会话。
- `/agents`：从服务端读取四类预设和可用 Chat 模型，创建配置、查看不可变版本、编辑并保留基础版本、CAS 发布或停止共享、测试固定配置。
- 发布面板展示实际配置 ID、已发布 ID、模型、空间、工具与工具范围。修改操作的 read/write/grant 授权仍由后端实时决定。
- 高级配置默认折叠。表单保留完整基础配置，名称编辑不会重置提示词、预算、token 上限或工具限制。工具范围明确区分继承、非空子集和空列表禁读；恢复继承需要显式操作。
- 无 Agent、无模型或无可用空间时提供配置入口；接口失败显示错误，不显示虚构成功状态。

## 运行、证据与权限

运行使用 SSE 的公开阶段事件；断线保留数字游标，刷新只从 sessionStorage 恢复数字游标。答案、提问、证据、模型事件正文和提示词均不写入浏览器持久化缓存。游标超出当前运行序号时重新回放。

`answer_block` 的正文不直接进入界面。收到该事件后读取已实时授权的 `GET /runs/{id}` 累计答案，并合并密集事件引发的刷新；`answer_complete=false` 标出仍在生成或未完整完成的部分。此方式同时兼容只提供阶段事件和最终答案的服务版本。前端不会展示规划文本、provider reasoning 或半截 JSON。

运行每 3 秒重新读取，历史列表每 5 秒重新读取；窗口重新聚焦时立即复核，运行还监听可见性恢复。任何读取失败清除对应内容；`content_hidden` 仅保留服务端安全运行元数据，并移除回答、问题、引用和打开的证据抽屉。旧请求响应不能覆盖新会话或更新的拒绝结果。

答案分为事实、推断和证据缺口。引用打开前重新读取运行，再读取不可变来源快照并校验资源、来源版本、位置和类型；原文读取失权也会撤下生成答案。Wiki 链接绑定知识修订，代码引用绑定源 commit 与行号。导出每次请求服务端授权接口，不导出浏览器缓存。重试和反馈的不确定响应复用同一逻辑操作的幂等键。

流式更新不调用自动滚动，不抢夺阅读位置。断开连接或关闭测试面板不会取消服务端运行；停止必须调用取消接口。

## 验证方式

```sh
cd web
npm test -- --maxWorkers=1
npm run typecheck
npm run lint
npm run build
```

新增行为测试位于 `src/test/agent-*.test.*`，覆盖：固定配置与运行 DTO、发布 CAS、折叠高级字段保留、编辑冲突、URL 恢复、权限撤销及迟到响应、引用失权、取消与幂等重试、受限导出、数字游标重连及刷新恢复、连续答案块的授权读取合并、阶段字段白名单，以及事实/推断/缺口展示。

这些是浏览器组件与 HTTP 契约模拟测试，不替代真实 Keycloak → gateway → Agent → 百炼的浏览器验收，也不替代真实企微机器人联调。新页面不修改原有 Wiki、来源和模型配置流程。完整界面验收需部署当前前端镜像，并使用配置好的实际身份、空间与模型进行问答、引用、反馈及撤权验证。
