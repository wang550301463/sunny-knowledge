# Versioned contracts and client generation

The checked-in contract version is `1.0.0`. `generated/openapi/*.json` exports
11 services, including gateway aggregation. `generated/coverage.json` records
actual coverage and remaining response gaps; it is not a claim that every domain
client has already been migrated.

From the repository root, after the existing locked Python and Web dependencies
are installed:

```sh
services/python/.venv/bin/python knowledge-docker/scripts/contract_generate.py
services/python/.venv/bin/python knowledge-docker/scripts/contract_generate.py --check
services/python/.venv/bin/python knowledge-docker/scripts/contract_verify.py
```

Generation uses the installed Python 3.12 dependencies, Go AST/parser/gofmt, and
locked Ruff. CI pins Python 3.12.12, Go 1.24.7, Node 20.20.2 and uv 0.8.17 and
installs from `uv.lock` and `package-lock.json`. It does not need service keys,
model credentials, databases, repositories, Docker startup, or outbound API calls.
An offline environment must already contain the locked dependencies. `CONTRACT_GO`
selects the Go exporter executable where multiple toolchains are installed;
`contract_verify.py --go PATH` selects the verification Go executable.

`--check` compares every generated byte and the file manifest, including stale
entries. Changes to a route, request model, response model, native Go JSON tags,
MCP tool input or gateway domain mapping must regenerate reviewed artifacts. No
clock values, deployment environment, absolute source paths or secrets enter the
output. Export disables app lifespans, telemetry and dotenv loading. Unknown
handler-local Go type collisions and unexported FastAPI routes fail generation
rather than silently pretending coverage.

## Source of truth

Python paths/parameters/request models come from actual FastAPI route objects.
Knowledge response DTOs derive SQLAlchemy columns from the same rows emitted by
its serializer, with explicit native types for JSON content. Agent response DTOs
reflect safe configuration and run views, including hidden runs and the native
public event union. `response_model_exclude_unset=True` preserves legacy missing
fields; response extensions are allowed and serialized rather than silently
removed. Response declarations do not weaken native publication, evidence,
lineage, time, ownership or authorization checks.

Go exports the actual registered handlers, dynamic IAM groups/departments,
direct handler wrappers, native JSON-tagged structs and supported serialization
expressions. Middleware/prefix mounts are inventoried separately. Go input decode
shapes do not infer key presence from output `omitempty` tags: required and
conditional business validation remain in the native handlers, while the original
serialization presence is retained as `x-go-serialization-required`. Unresolved
output expressions retain `x-response-typing: untyped` and explicit unresolved
markers. No `Any` success response is invented to close the coverage count.

Gateway operations come from the native `domains` routing map and matching real
upstream public routes. Its two health branches and protocol/proxy mounts are
recorded. Graphiti's `/api/v1/graph/traverse` currently has no gateway domain route;
this appears in `unrouted_public_routes`. The existing user workflow uses
retrieval's `/api/v1/traverse`; generation does not change gateway exposure.

MCP `/mcp` is Streamable HTTP, not a set of invented REST paths. Its six tool
inputs are exported from the native SDK-facing `TOOL_INPUTS` adapters under
`x-mcp-tools`; protocol/session/cancellation/OAuth behavior remains SDK-owned.
Agent SSE has `text/event-stream` plus its `x-event-schema`. LLM `/internal/v1/chat`
records its actual conditional JSON/SSE transport; inference output DTOs remain a
listed gap. Native Python validation error envelopes replace FastAPI's default
422 documentation where the app has its own exception serializer.

## Generated clients and real adoption

- Python: `services/python/src/knowledge_platform/generated_contracts/{types,operations}.py`.
  Types describe known JSON shapes; the handwritten `client.py` prepares frozen
  JSON bytes and can call the existing `HTTPAuthorizer.request` transport.
- Go: `services/go/internal/generatedcontracts/operations.go` and the small
  handwritten transport-neutral `client.go`. `native/types.go` aliases native
  platform/IAM/channel DTOs in a separate package to avoid a dependency cycle in
  domain transports. Go does not fabricate cross-language response decoders.
- TypeScript: `generated/typescript/{types,operations,client}.ts`. The runtime and
  tree-shakeable operation exports are also generated into
  `web/src/generated-contracts`, inside the existing Web image build context.
  The runtime source is `contracts/runtime/typescript/client.ts`.

Operations carry only service, method, relative path template, declared parameter
names, transport and schema references. They cannot select arbitrary URLs or
persist tokens. Preparation percent-encodes literal path segments, rejects dot
segments, undeclared query/header parameters and credential headers, copies JSON
bodies, and preserves empty arrays versus null. Typed responses are static wire
shapes; callers must retain native runtime validation. Untyped operations have
no generated response type alias and return the existing raw HTTP response.
SSE readers retain their existing cancellation, cursor and live authorization
logic; generation does not add automatic mutation retries or a response cache.

Actual migrated production call sites are Python `HTTPAuthorizer.resolve` and
`authorize`, Go `platform.Client.Resolve`, and the Web lifecycle metadata GET.
They still use the existing workload signing, original bearer, configured origin,
timeout, response validation and ACL logic. The remaining domain calls retain
handwritten transports and are not counted as migrated merely because a matching
operation was generated.

`EvidenceRef.revision_id` is an immutable **source snapshot** ID. The outer
citation or Wiki revision's `revision_id` is a **Wiki revision** ID. Generated
schemas keep these fields in their distinct containing models; summaries or
input Wiki lineage do not turn into additional original evidence.

## Coverage and remaining work

The initial inventory contains **174 backend HTTP operations**: **94 typed JSON
responses, 76 explicitly untyped responses, 3 Agent SSE operations and 1 Markdown
export**. Gateway adds 100 routed/health operations (mirrors, not 100 additional
domain behaviors). Exact operation IDs and per-service totals are machine-readable
in `generated/coverage.json`.

Most remaining response declarations belong to ingest, retrieval, LLM, graph
results, lifecycle/projection internals, some Agent management/history routes,
OAuth metadata and a few Go dynamic broker/administration serializers. Their
request declarations and routes are still inventoried; missing outputs are not
replaced with empty "complete" models. Continue source-owned DTO additions with
actual serializer compatibility tests, then migrate callers using the existing
security transport. JSON Schema cannot replace imperative validators, current
ACL checks, temporal proof, idempotency or concurrency tests.
