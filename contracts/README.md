# V2 service contract (v1)

All runtime services listen on `:8080`. Internal service DNS equals service name. Public origin http://localhost:18080 through gateway only; Keycloak public prefix /idp, realm knowledge. Service databases `knowledge_<name>` / roles `<name>`. Names: iam, auth, channel, knowledge, ingest, retrieval, llm, graphiti, agent, mcp (gateway stateless). Parent owns shared Go/Python deps and Compose unless assigned explicitly.

## Trust
External request has Bearer Keycloak token. Gateway removes X-Principal*, X-User*, X-Role*, X-Service*, X-Internal*, X-Forwarded* then uses its own signed service identity when calling auth. Internal HTTP uses `X-Service-Token` per-caller HS256 JWT with issuer `knowledge-services`, audience target service, subject caller, exp<=60s; key env SERVICE_JWT_SECRET shared for development (private Compose secrets generated locally). End-user Bearer token forwarded unchanged and revalidated through auth. Never trust caller-provided JSON principal from public requests. Authorization cache default disabled until epoch-safe implementation.

## Auth API (internal service authenticated)
`POST /internal/v1/resolve` body {} plus Authorization → `{principal: {id, subjects:["user:<id>","group:<id>","department:<id>","service:<id>"], permissions:[], auth_epoch:int}, scopes:[]}`. `POST /internal/v1/authorize` body `{action:"read"|"write"|"grant"|"review",space_id,resource_id?:string}` → `{allowed,auth_epoch,acl_domain,acl_version}`; endpoint resolves own principal from Bearer. No provided principal accepted. Batch `/internal/v1/authorize-batch` `{action,resources:[{space_id,resource_id}]}` → `{decisions:[{space_id,resource_id,allowed,acl_domain,acl_version}],auth_epoch}`.

## IAM policy API (service authenticated, only auth/knowledge/ingest/retrieval/graphiti may use appropriate reads)
`GET /internal/v1/principals/{sub}` → principal as above. Keycloak sub is platform principal id. `POST /internal/v1/check` `{principal_id,action,space_id,resource_id?}` → same decision (auth caller only). `GET /internal/v1/policies/{space_id}/{resource_id}` → `{space_id,resource_id,space_read_subjects:[],resource_read_subjects:null|[],acl_version,acl_domain,auth_epoch}` (projection callers only). Resource ACL null inherits; [] denies everyone. ACL domain is sha256 canonical JSON space+sorted space subjects+sorted resource subjects/null. IAM owns all ACLs. Space creation grants actor explicit read/write/grant/review; platform_admin management alone no read. Public `/api/v1/spaces`, `/api/v1/groups`, `/api/v1/departments`, `/api/v1/users`, `/api/v1/grants` via IAM.

## Canonical knowledge
Public `/api/v1/pages` list/create; GET /pages/{id}; POST /pages/{id}/proposals; GET /pages/{id}/revisions; GET /pages/{id}/revisions/{rev}; GET /reviews; POST /reviews/{id}/approve|reject; POST /pages/{id}/rollback. Immutable revision `id` UUID string, page current_revision nullable for draft. `EvidenceRef`: resource_id,revision_id,source_id,source_revision,path,start_line,end_line,valid_from,valid_until,kind. API response lists `{items:[],next_cursor?:string}`. Errors `{error:{code,message,request_id?}}`. Dates UTC ISO8601, IDs strings UUID unless explicit namespaced key. Outbox claimed/acked by projection through service-authenticated internal API; never another service SQL. Principal token and input evidence authorization required on ingest writes; no auto-publish endpoint for arbitrary public users.

## Python layout
`services/python/pyproject.toml` package root; src/knowledge_platform/common plus knowledge/ingest/retrieval/llm/graphiti/agent/mcp. Uvicorn module `knowledge_platform.<service>.app:app`. Shared config `DATABASE_URL`, SERVICE_NAME, SERVICE_JWT_SECRET, AUTH_URL, IAM_URL; async SQLAlchemy+psycopg for PG. Tests per tests/<service>. Parent creates common config/db/security/auth/error utilities. Parser task standalone ingest/analyzers, no service dependencies.
