# 美术画室平台开发验收记录 · 2026-09-08

代码位于独立工作树 `.worktrees/art-platform`，分支 `codex/art-platform`；原主工作树未覆盖，旧单体归档到 `legacy/monolith`。这是一份开发交付记录，不是正式上线批准或微信/OSS/支付商户验收证明。

## 已交付

八个独立业务服务、独立数据库及账号、独立镜像、Compose 开发/正式配置、私有入口与安全接入、Outbox/Inbox、监控及恢复工具。PC 保留现有视觉基础，新增教学内容、班级主题、批量作品整理、家庭管理、成长展览、招生和基础商城运营页面。原生 TypeScript 小程序包含老师、家长及游客入口，身份由服务端切换。

教学链路支持主题模板固定版本、多班独立推进、2–4 课次、学生补课状态、每课过程记录、合作作品、完整课效版本、撤回和家庭授权。媒体使用上传后封存与短签名；复用必须证明上传者或显式业务来源权限。展览授权与家庭查看分离。交易实现签名/验签、付款与权益状态分离、幂等补偿、退款冻结、履约和对账；正式支付仍需真实商户验证。

## 实际运行验证

- 八个服务启动健康。服务账号读取本库成功、跨库读取被 MySQL 拒绝；身份/教务 Redis 可写自己的前缀，外来前缀和全局枚举均被拒绝。
- 八个正在运行的服务均实际执行 JDBC 临时表验证：JVM 与会话时区为 Asia/Shanghai；新事件立即到期，SQL 当前时间偏差 0–1 秒；Instant 往返及 09:30 课表保持正确。
- 两校区、两固定班、每班三学生的真实 HTTP 链路成功：三课次记录、上传确认、固定课效、重复发布同版本、课时余额不变、家庭绑定审批、草稿隔离、私有媒体实际下载、课表和课效事件到达家长站内消息、解除绑定后返回 403、主题扩展第四课次且模板不变。
- 独立更新服务后验证网关动态 DNS 寻址；登录入口覆盖客户端伪造的转发 IP 头，内部凭证头不向业务服务透传。
- 合成图片压测：并发 8，200 次作品读取及 16 次约 3 MB 上传，0 错误；读取 p95 约 292 ms，上传完整流程 p95 约 372 ms。本机 Docker Desktop 结果只说明此样本，不表示生产容量。报告含容器内存、连接池与事件积压。
- 八数据库备份成功导入随机命名临时 MySQL，校验摘要及恢复结果；最终备份使用暂停业务服务的跨库一致点，并核对逐表行数。恢复检查不覆盖现有业务库。
