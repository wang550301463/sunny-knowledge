# 美术宝轻透工作空间 · 实施与验证

日期：2026-09-08。目标：将柔和半透明 Mac 视觉方向落实到当前业务 Demo，并修复现有搜索、课表、请假流程。研究依据和实施范围见 `docs/socrates/plans/2026-09-08-art-studio-glass-plan.md`。

## 已实现

- 磨砂侧栏和工具栏、柔和环境色、白色阅读面、清晰的焦点和减少动态效果支持。
- 美术宝品牌与艺术纸张构图、桌面双栏/窄屏单栏登录页。
- 导航按工作空间、日常教学、教学资源、机构设置分组；移除无效通知，收起状态有可访问名称；移动导航可滚动。
- 按实际角色选择机构/教学首页，统计权限独立控制。校区可切换，展示真实指标；今日课次按时间排序，取消课次不计入有效课次；空态提供本周下一课入口。
- 搜索支持学员、家长、分组和课次的有效深链接；按目标权限筛选，处理输入法、防抖、请求竞态和错误重试。空校区非超管搜索不再放宽为全局范围。
- 教师周课表可用键盘打开课次，深链接定位正确周和校区；名单只请求当前课次。创建、调课和取消入口受权限控制。
- 请假按姓名/编号选择学员、锁定预选学员、校验日期顺序、区分失败与空态、审批成功刷新并关闭旧详情；学员档案展示其本人请假记录。
- 登录/退出清理查询缓存；请假学员搜索缓存按账号和校区范围隔离；退出过程中的状态订阅保持引用稳定。
